# 🐧 LostPengu Project Documentation

## Overview
LostPengu is an experimental autonomous AI Agent ecosystem built on Solana.

The project combines:
- AI Agents
- Meme generation
- Autonomous workflows
- Community interaction
- Open-source development

LostPengu is designed as a living AI colony where agents can evolve, generate content, and improve the ecosystem over time.

---

# 🚀 Core Systems

## 1. Meme Generator
Interactive meme creation system powered by LostPengu AI visuals.

Features:
- Custom captions
- PNG export
- AI themed templates
- Social media ready outputs

---

## 2. Autonomous Agents
LostPengu contains automated GitHub workflow agents.

Current agents:
- Code Agent
- Meme Agent
- Daily Agent

These agents automatically:
- Update files
- Generate logs
- Improve workflows
- Maintain activity
